# File-Organizer
A Python-based File Organizer is a Python script designed to automate the process of organizing and managing files within a specified directory by moving them into subfolders based on their file types (extensions). For example, it can place .jpg files into an "Images" folder and .pdf files into a "Documents" folder. It typically categorizes files based on their extensions or other metadata and moves them into organized subfolders, thereby saving time and improving file accessibility. The script typically uses the os and shutil libraries to list, create, and move files, and can be configured using a separate JSON file to define custom folder mappings for different file extensions.
